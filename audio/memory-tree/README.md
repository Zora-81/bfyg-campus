# 记忆树背景音乐

把 MP3 文件放到此目录，文件名与 `js/memory-tree.js` 中 `MUSIC_PLAYLIST` 的 `url` 对应即可。

默认播放列表：

| 文件名 | 歌名 | 歌手 |
|--------|------|------|
| track-1.mp3 | 小半 | 陈粒 |
| track-3.mp3 | Angel | 尹美莱（占位，未提供文件时自动回退合成音）|

> 注意：示例中的《小半》《Angel》受版权保护。当前 `track-1.mp3` 为本地已有的陈粒《小半》，仅限个人/授权场景使用；公开站点上线前请确认已获授权或替换为自有音乐。

如果没有放置合法 MP3，播放器会自动回退到 `three-scene.js` 生成的合成环境音。
