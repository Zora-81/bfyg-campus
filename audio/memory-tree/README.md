# 记忆树背景音乐

把 MP3 文件放到此目录，文件名与 `js/memory-tree.js` 中 `MUSIC_PLAYLIST` 的 `url` 对应即可。

默认播放列表：

| 文件名 | 歌名 | 歌手 |
|--------|------|------|
| track-1.mp3 | 星空旋律 | 记忆树原声 |
| track-2.mp3 | 小半 | 陈粒 |
| track-3.mp3 | Angel | 尹美莱 |

> 注意：示例中的《小半》《Angel》为 BobZhang 个人主页同款曲目，受版权保护，**请勿直接用于公开站点**。请替换为你自己拥有版权或合法授权的音乐。

如果没有放置 MP3，播放器会自动回退到 `three-scene.js` 生成的合成环境音。
